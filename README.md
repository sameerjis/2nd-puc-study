# 2nd PUC Study Materials

Karnataka 2nd PUC (Class XII) study resources — official textbooks, chapter notes, and teacher-style audio lessons.

> From 2024-25 onward, Karnataka PUE adopted **NCERT Class XII textbooks** for 2nd PUC science subjects. The textbooks here are the official latest editions.
